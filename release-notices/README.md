# Version-specific dependency notices

These older published Apple-binding crates omit the repository license files from
their crates.io archive. Their exact upstream LICENSE.md is preserved here from
the commit in .cargo_vcs_info.json, together with unmodified canonical MIT terms
from the versioned SPDX license-list-data project. Original author metadata is
recorded in the generated notice index; no copyright notice is fabricated.

Every file has a source URL and SHA-256 in provenance.json. The packager validates
name, version, upstream revision and file hashes, and includes these declarations,
terms and provenance only for dependencies present in the selected target graph.
The packager never downloads notices. Updates require explicit review of upstream
metadata/notices; unknown missing-license versions still fail packaging. Review
upstream declarations and attribution requirements before public publication.
